# 🦖 Dinosaur War Arena (DWA)

## Project Overview
Dinosaur War Arena is a dinosaur battle simulation project featuring 2D and 3D environments, intelligent AI-controlled dinosaurs, combat mechanics, and realistic animations.

## Main Source Code
- `BAOHUY_Dinosaur_War_Arena_Enhanced(1).html`
- HTML source file containing VFX, Shader and Audio enhancements.

## Development Goals
- Build and integrate 100 functional AI agents.
- Test AI behavior, stability, and combat performance.
- Improve dinosaur movement and combat animations:
  - Walk
  - Run
  - Roar
  - Attack
  - Death
  - Special
- Improve environments, visual effects, and sound.
- Optimize performance for mobile devices.

## Development Rules
- Preserve existing project features whenever possible.
- Do not add new dinosaur species or individuals without user-provided images and explicit approval.
- Do not impose a limit on the number of individuals per species.
- Test changes before considering them complete.

Source files are being uploaded. AI integration and testing are pending.
